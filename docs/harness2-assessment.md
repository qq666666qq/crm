# Harness² 与当前手动评测的对照

原交接允许参考 Harness² 思路实现独立流程。当前应用没有安装或调用官方 Harness²。官方项目的[安装说明](https://github.com/google-research/harness2/blob/main/docs/SETUP.md)要求基准运行环境使用 Linux、Python 3.12（包也支持 3.13），并列出模型凭证及部分基准的额外依赖。其[项目说明](https://github.com/google-research/harness2)列出支持的执行器；没有证据表明存在可直接安装的 Pi Durable 执行器。本项目尚未验证 Windows 上可用的官方隔离执行环境。

| 交接要求 | 当前状态 |
| --- | --- |
| 用户主动启动 | 已有：用户在技能页面点击对照评测；默认不会运行官方 Harness² 或自动启动评测。 |
| 选择 Skill 和用例 | 部分：目前只支持线索提取技能；可选候选版本并填写 1 至 3 条用例，用例在桌面端加密保存。 |
| 隔离运行 | 未完成：评测使用独立模型调用，不开放 CRM 工具；这不构成进程、文件系统或网络隔离。数据仍发送给用户配置的模型提供商。 |
| 前后版本比较 | 部分：同一用例分别请求基线和候选；程序只检查是否包含用户指定的文字，不验证语义或事实。 |
| 人工审核和发布 | 已有基本流程：用户查看候选和结果并手动发布；未通过、用例改变或基线改变时不能发布，历史版本可回滚。 |

当前测试以模拟模型验证流程和边界；没有运行官方 Harness²、真实 Linux 隔离基准或真实外部模型端到端验收。不能依据这套文字检查宣称已完成隔离回归或证明业务事实正确。官方适配仍需确认 Pi 执行器接口、隔离执行环境及安全限制，完成后再做真实集成验证。
